# Firebase / FlutterFire
# 1. Instale FlutterFire CLI e rode: dart pub global activate flutterfire_cli
# 2. flutterfire configure --project=SEU_PROJETO
# 3. Defina FIREBASE_ENABLED=true no .env
# 4. Coloque google-services.json em android/app/

Este diretório guarda config de Hosting opcional.

Para Hosting do Flutter Web:
```
flutter build web
firebase init hosting
firebase deploy
```
