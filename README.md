# EBD — Livro de Registro

App Flutter da **Escola Bíblica Dominical** (pacote `br.com.ebd.livro_registro`).

Projeto **recuperado** a partir do APK instalado no celular + backups JSON + protótipo JSX, após falha do HD. Detalhes em [`docs/AUDITORIA_RECUPERACAO.md`](docs/AUDITORIA_RECUPERACAO.md).

## Rodar

```bash
flutter pub get
flutter run
```

Para restaurar os dados do aparelho: no app, **Backup → Restaurar** e escolha `reference/ebd-backup26-07-2026A.json`.
